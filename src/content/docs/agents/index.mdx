Los agentes de código se conectan al servidor MCP de RunRunApi por HTTP: basta declarar la URL y elegir autenticación (OAuth, o un API key de sesión de la REST como Bearer). Claude Code y Codex tienen guía propia; cualquier otro cliente MCP sigue los mismos tres datos: URL, autenticación y listado de herramientas.
